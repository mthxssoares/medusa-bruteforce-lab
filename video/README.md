# Laboratório de Força Bruta com Medusa e Kali Linux

Este projeto apresenta um laboratório prático de cibersegurança realizado em ambiente virtual controlado e autorizado, com foco na análise de testes automatizados de autenticação utilizando a ferramenta Medusa.

## 🎥 Demonstração em vídeo

Assista à demonstração do laboratório:

▶️ [Laboratório de Força Bruta com Medusa e Kali Linux](https://youtu.be/7ah-nY60RG8)

## 🛠️ Ferramentas utilizadas

- Kali Linux
- Metasploitable
- Nmap
- Medusa
- VirtualBox

## 📄 Relatório técnico

O repositório também contém o relatório técnico completo com as etapas, evidências, resultados, análise de segurança e medidas de mitigação.

## ⚠️ Aviso

Este projeto foi desenvolvido exclusivamente para fins educacionais. Todos os testes foram realizados em ambiente virtual controlado e autorizado.
